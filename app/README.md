# Blind Vault — web app

Next.js UI for **Rocco’s Lock-Up Auctions** (Blind Vault).

- Brand mark: `public/brand/logo.png` (blindfolded octopus)
- Dev: from repo root → `npm run dev`
- Typecheck / build: `npm run typecheck` · `npm run build`

Env: copy root `.env.example` → `app/.env.local` (Devnet RPC + program id).

See the root [README](../README.md) for architecture, addresses, and operator scripts.
